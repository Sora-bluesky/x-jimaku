# 動作要件と実測値

[English](requirements.md) | [日本語](requirements.ja.md)

x-jimakuには、WebGPUとGPUアダプターを利用できるChrome 138以降が必要です。PLaMoの翻訳にCPUへのフォールバックはありません。モデルの保存容量と、初回取得用のインターネット接続が必要です。WhisperはPLaMoとは別に取得します。以下の容量はPLaMoだけの値です。

## モデルのサイズを選ぶ前に

測定環境はRTX 4070 12GB、Windows 11、Chrome Canary 159の単一構成です。ほかのGPUは未測定です。ほかのOSもここでは動作確認していません。表は拡張の実際のオフスクリーンドキュメント内で、pfnetのQ4_K_MのGGUFモデルと、手元でビルドしたWebGPU対応wllamaを使った試作時の実測値です。最低VRAMの仕様や、製品全体の測定値ではありません。

| 項目 | 0.8B（既定） | 2B | 8B |
| --- | ---: | ---: | ---: |
| PLaMoのファイル容量 | 573,126,848バイト | 1,807,203,040バイト | 5,280,445,728バイト |
| WebGPUに載った層 | 17 / 17 | 25 / 25 | 33 / 33 |
| 初回読込、取得込み | 63.8秒 | 287.8秒 | 896.9秒 |
| 保存済みでの読込 | 4.4秒 | 6.0秒 | 12.8秒 |
| 1行あたりの翻訳、p50 / p95、40行 | 499 / 604ms | 569 / 639ms | 779 / 973ms |
| ピークGPUメモリ増分、PLaMo単独 | +949MiB | +2,177MiB | +5,337MiB |
| Whisper baseと同時のピークGPUメモリ増分 | +1,436MiB | +2,840MiB | 未測定 |
| 製品経路の品質と遅延 | 下記で測定 | 未測定 | 未測定 |

容量はモデルファイルの値で、保存に使う総容量ではありません。Whisperとブラウザの保存領域も必要です。GPUメモリの増分はこの機材での観測値であり、GPUの最低容量ではありません。8BとWhisperを同時に動かした場合の推定値は載せていません。

試作時の測定方法は次のとおりです。

- 初回読込はHugging Faceからの取得を含むため、回線速度に左右されます。表は行ごとの翻訳試験を完走した回の値です。保存済みの読込は、取得済みのモデルを別途読み込んだ値です。
- 行ごとの翻訳試験では、`bench/refs/tts2-script.txt`の5文を8周して40行にしました。翻訳履歴・用語辞書は使わず、`max_tokens=128`、温度はゼロです。p95は40点の線形補間です。
- GPUメモリは`nvidia-smi --query-gpu=memory.used`で0.5秒ごとに取得しました。実行中の最大値からChrome起動前の使用量を引いています。ChromeだけではなくGPU全体の値です。PLaMo単独のピークは2回のモデル読込中の最大値です。
- Whisper baseとの同時実行は、測定した各サイズで1回ずつの短い試作試験です。長時間の安定性を実証したものではありません。8Bとの同時実行は測っていません。

p50は中央値です。p90とp95は、観測した遅延の分布の遅い側を示します。試作の行ごとの時間には、音声認識と字幕表示は含みません。

## 取得時間の計算例

以下は実測ではなく計算値です。上記の正確なファイル容量と一定の実効転送速度を使い、`秒 = バイト数 × 8 / (Mbit/s × 1,000,000)`で求め、小数点以下1桁に丸めています。接続の追加時間、検証、読込、別途取得するWhisperは含みません。実際の初回読込は、これより長くなる場合があります。

| PLaMoのサイズ | 10Mbit/sの場合 | 50Mbit/sの場合 | 100Mbit/sの場合 |
| --- | ---: | ---: | ---: |
| 0.8B | 458.5秒 | 91.7秒 | 45.9秒 |
| 2B | 1,445.8秒 | 289.2秒 | 144.6秒 |
| 8B | 4,224.4秒 | 844.9秒 | 422.4秒 |

## 製品経路の実測

製品全体を通した測定は0.8Bだけです。同じ機材でWhisper baseと英語原文の併記を有効にし、リポジトリのベンチを5回実行しました。

```sh
node bench/live2.mjs --case tts2 --model base --plamo-model 0.8b --show-original
```

次の件数は5回の合計です。比較対象はv0.7.0のPrompt API版を5回実行した基準値です。

| 指標 | PLaMo 0.8B | v0.7.0のPrompt API基準値 |
| --- | ---: | ---: |
| `englishPassthrough`：日本語を含まない出力行 | 0 | 1 |
| `wrongSenseRoma`：「ローマ」の直後に「ン」がない出力 | 0 | 0 |
| `unresolvedPlaceholders`：未解決の`%%` | 0 | 0 |
| `romanKept`：英単語のRomanが出力に残るもの | 0 | 1 |

これらは、この試験素材の特定の失敗パターンを数えた指標です。翻訳品質全般の点数ではありません。

音声内の対応する台本の文の終了から日本語字幕ページが表示されるまでの遅延は、各実行で台本の文と対応付けできた字幕88ページを合算してp50が2.58秒、p90が4.50秒でした。28ページは対応付けできませんでした。実行ごとのp50は2.0〜4.2秒でした。製品経路の1行あたりの翻訳は、実行ごとのp50が0.60〜0.78秒（実行ごとのp50は604〜783ミリ秒）でした。こちらは製品の翻訳文脈を含むため、上の試作試験とは条件が異なります。

同じ実行で、字幕を読むのに必要な速さも測定しました。

| 日本語の毎秒文字数 | その速さを超えたページ数の割合 | その速さを超えた表示時間の割合 |
| --- | ---: | ---: |
| 7 | 60％ | 42％ |
| 4 | 72％ | 58％ |

割合は丸めた値です。表示された本文と時間の観測であり、読む速さの目標値や利用者の読解試験ではありません。翻訳が速く終わっても、字幕を読み切れない場合があります。

## サイズを選ぶときの考え方

既定の0.8Bだけが、製品全体を通して測定されています。測定機では、この結果を出発点にしてください。試作の表からは、2Bや8Bで製品の翻訳品質が改善するとは言えません。この両サイズの製品経路での品質と遅延は未測定です。ほかのGPUに対する推奨サイズは示しません。

## 自分のPCで確認する

字幕を停止し、拡張のオプションページでPLaMoのサイズと訳し方を選び、「このPCで試す」を押してください。次の情報を表示します。

- WebGPUとアダプターを利用できるか、Chromeが公開するアダプター情報です。
- `maxBufferSize`と`maxStorageBufferBindingSize`です。
- 必要な場合の取得・検証を含めたモデル読込時間です。
- 短い英文3文の訳と、各文の翻訳時間です。

WebGPUやアダプターがない場合は、取得前に終了します。選んだモデルが未保存の場合は取得します。字幕表示とは別に動くため、Whisperとの同時実行や、発話から字幕までの遅延は測りません。アダプターの上限値は参考情報であり、モデルがメモリに収まるかどうかを判定する機能ではありません。
